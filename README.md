# Personal Portfolio Website

A simple personal portfolio website built as my **first web development project** using HTML and CSS.

## 📌 Overview

This project was created to apply the fundamentals of web development and build a basic personal portfolio website.

The website introduces me, highlights my role and provides a simple way to access my contact information.

## 🛠️ Technologies Used

* **HTML5** – Used to create the structure and content of the website.
* **CSS3** – Used for styling, colors, spacing, typography, and layout.

## ✨ Features

* Personal introduction
* About Me section
* Contact link
* Clean and simple layout
* Custom CSS styling

## 📚 Concepts Practiced

While building this project, I practiced:

* HTML document structure
* Semantic HTML elements
* CSS selectors
* Colors and typography
* Margin and padding
* CSS box model
* Basic layouts
* Links and navigation
* Section-based webpage design

## 🎯 Purpose

The main purpose of this project was to strengthen my understanding of **HTML and CSS** by building a website from scratch rather than following a ready-made template.

This project represents the beginning of my journey into **web development**.
